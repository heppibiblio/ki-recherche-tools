# Mitwirken

Vielen Dank für das Interesse an der Mitarbeit an den **KI-Recherche-Tools**.

Diese Sammlung soll kollaborativ gepflegt und laufend aktualisiert werden.  
Beiträge von Kolleg:innen aus wissenschaftlichen Bibliotheken sind ausdrücklich willkommen.

## Wie kann man mitwirken?

Mögliche Beiträge sind zum Beispiel:

- neue Tools vorschlagen
- bestehende Einträge korrigieren oder ergänzen
- Hinweise zu Kosten, Datenbasis oder LibKey geben
- veraltete Informationen melden
- bibliotheksspezifische Tool-Auswahlen ergänzen

## So funktioniert die Mitarbeit

### 1. Vorschlag einreichen
Neue Tools oder Änderungen können als **Issue** oder per **Pull Request** eingereicht werden.

### 2. Prüfung
Ein Mitglied der Redaktion prüft den Vorschlag auf:
- Plausibilität
- Aktualität
- Vollständigkeit
- Konsistenz mit dem Metadatenschema

### 3. Übernahme
Wenn der Vorschlag passt, wird er in das Repository aufgenommen.

## Bitte beachten

- Bitte nur offizielle URLs verwenden.
- Angaben nach Möglichkeit belegen oder kurz begründen.
- Das Feld `last_checked` sollte aktualisiert werden.
- Wenn möglich, bitte die Datei eindeutig benennen, z. B. `connected-papers.json`.

## Technische Hinweise

- Ein Tool entspricht in der Regel einer JSON-Datei in `tools/`.
- Bibliotheksspezifische Auswahlen werden in `collections/` abgelegt.
- Bitte das Metadatenschema in `docs/schema.md` beachten.
